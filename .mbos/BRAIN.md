# 🧠 Mi Condo Web App - BRAIN

## Core Architecture
- **Frontend**: React + Vite + TypeScript.
- **Backend**: Supabase (PostgreSQL + Auth + Realtime).
- **Styling**: Tailwind CSS + Glassmorphism.

## Principles
- **Realtime First**: Use Supabase Realtime for live updates (e.g., Elisa AI Dashboard).
- **Glassmorphism Aesthetics**: Premium look with transparencies and blurs.
- **Tenant Isolation**: Data filtered by `condo_id`.
